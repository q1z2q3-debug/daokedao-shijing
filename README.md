# 润泽说 道可道之诗经

> 《诗经》三百五篇通释读本。底本《毛诗正义》经文，参校朱熹《诗集传》、王先谦《诗三家义集疏》。
> 作者：润泽（润泽博士）· 在线读：<https://q1z2q3-debug.github.io/daokedao-shijing/> · v0.3.58（卫风三篇·硕人）

## 是什么

一篇一页，按《毛诗》分篇：国风一百六十、小雅七十四、大雅三十一、周颂三十一、鲁颂四、商颂五，凡三百五篇。篇号 `SJ001`–`SJ305` 连排固定，风、雅、颂三体在这一条序列里各自成段。

每篇十一节（解题、经文、韵读、字义与名物、今译、章旨、诗教、分寸与边界、存疑、跨典、双卡与图）。四层分离：经文【经】、训诂【训】、诗义【义】、诗教【教】，一段只归一层。

两条自立的规矩：

- **诗三判**：每篇解题须答三句——此诗谁在说／说的是一件什么事／它凭什么被编在这里。第三句缺席，视为该篇未写完。
- **从物入，不从志入**：《诗》以草木鸟兽虫鱼为骨。每篇至少落一件可指着说的名物（一株荇菜、一只雎鸠、一领缁衣、一条淇水），义从物上长出来，不从序上抄下来。

## 为什么先做这一部

五经之中，「书」已成《尚书》，「易」已成《易传》，「诗」是唯一未动的一部；且已成的《孟子》三十余处「《诗》云」、《论语》两处引诗，都要一个能回指的源头。先做诗，等于给已成的几部把引证的根补上。

## 体例要点

- **不遵《诗序》为定论**。《毛序》每篇一句「美刺」，汉人以政教解诗，多有为而发。本库把《序》与朱子《诗集传》的异说并列，凡两读皆通者，取「文本能自证」的一读为主，另一读入存疑。
- **韵读标在经文上**。每章末字押什么韵、古音属何部，逐章标出；叶韵之改读，只标不改字。
- **名物必落形**。草木鸟兽、器物衣冠，皆附一句可指认的形貌或用途，不写「一种植物」了事。
- **诗教单列一节**。兴、观、群、怨四字出于《论语》，本库用它作诗教的四问：此诗兴什么、可观什么、可与谁群、可怨什么。不作道德教训。

## 结构

- `book/` 三百五篇源稿（`SJ001`–`SJ305`），一篇一文件，命名 `SJ%03d-篇题.md`；`体例.md` 为唯一体例源。
- `book/chapters.json` 风、雅、颂、篇号、篇题、文件、页面、图键的机器可读表（`count` 记篇数，`pages` 记页数）。
- `assets/fig/` 手写 SVG 义理图，一图一文件，画幅 760×540，纸墨五色。
- `scripts/` 构建与审计脚本；`docs/` 站点（GitHub Pages，`main:/docs`）。
